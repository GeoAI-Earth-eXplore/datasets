# Datasets

A curated collection of datasets for GeoAI, Earth observation, remote sensing, GIS, and environmental applications.

## Categories

### Satellite and Aerial Imagery
High-resolution and multispectral imagery resources, including aerial and satellite data platforms.

### LiDAR and 3D Geospatial Data
LiDAR point clouds, canopy height models, elevation products, and other 3D geospatial datasets.

### Land Cover and Land Use
National and global land-cover, land-use, and surface characterization datasets.

### Agriculture
Crop type, agricultural land, field boundary, and other agriculture-related datasets.

### Forests and Vegetation
Tree crowns, canopy structure, species classification, vegetation mapping, and forestry datasets.

### Biomass and Carbon
Aboveground biomass, forest carbon, and related environmental datasets.

### Protected Lands and Parks
Protected areas, parks, conservation lands, visitation, and recreation datasets.

### Socioeconomic and Demographic Data
Population, demographic, parcel, socioeconomic, and related geospatial datasets.

### Benchmarks
Datasets designed for benchmarking GeoAI, remote sensing, object detection, segmentation, classification, and multimodal models.

## Contributing

Contributions are welcome. If you know of a useful dataset that should be included, please submit a pull request or open an issue.
